# AxeHax
A utility for patching PlayStation All-Stars Battle Royale for the PlayStation 3 to use the official All-Stars Matchmaker mod.

## Downloading

You can download AxeHax for your platform by visiting our Releases.

https://github.com/Project-RePSASBR/AxeHax/releases/latest

## Credits/Libraries we use
This tool is heavily based on Refresher, a similar utility developed by the LittleBigRefresh team for patching LittleBigPlanet.

### UI
- Eto.Forms
- CommandLineParser

### Patching
- ELFSharp
- SPRXPatcher
- SCEToolSharp
- LittleBigRefresh's C# port of jjolano's make_fself

### Connections
- WebMAN (technically)
- FluentFTP
